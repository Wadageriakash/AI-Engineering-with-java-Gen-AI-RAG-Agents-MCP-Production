# AI-Engineering-with-java-Gen-AI-RAG-Agents-MCP-Production


Steps involved when you ask ChatGPT a question
1. User enters a question (Prompt).
2. Prompt is sent to the ChatGPT server.
3. Text is tokenized into smaller units (Tokens).
4. Tokens are converted into numerical representations (Embeddings).
5. Input is processed by the Transformer architecture.
6. Attention mechanism identifies relationships between tokens.
7. Neural network layers process the information.
8. The model calculates probabilities for the next token.
9. The next token is selected.
10. The process repeats to generate subsequent tokens.
11. Generated tokens are converted back into readable text.
12. Response is streamed back to the user.
13. User receives the final answer.
